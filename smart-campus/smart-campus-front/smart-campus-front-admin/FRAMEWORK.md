# 智慧校园后台管理系统

## 项目概述

智慧校园后台管理系统前端工程，基于 Vue 3 + Element Plus 构建的管理后台应用。

## 技术栈

- **Vue 3.5+** - 使用 Composition API 和 `<script setup>`
- **Vue Router 4** - 路由管理
- **Pinia** - 状态管理
- **Element Plus** - UI 组件库
- **Axios** - HTTP 请求
- **Sass** - CSS 预处理器
- **Vite** - 构建工具

## 界面设计

### 布局结构

整体采用简洁清爽的蓝色调设计，页面分为两部分：

#### 1. 顶部导航栏（60px 高度）
- **左侧**：Logo + "智慧校园后台" 项目名称
- **中间**：一级菜单（水平排列）
  - 选中状态：底部蓝色下边框
- **右侧**：用户信息下拉菜单

#### 2. 主体内容区（分左右两栏）
- **左侧菜单栏**（200px 宽度）
  - 显示当前选中一级菜单的名称
  - 展示二级菜单列表
  - 选中状态：蓝色渐变背景
  - 使用卡片样式
- **右侧内容区**（自适应宽度）
  - 显示具体功能页面
  - 使用卡片样式

## 核心功能

### 路由管理
- 集中式路由配置
- 路由守卫：未登录跳转、菜单权限校验
- 动态页面标题

### 状态管理
- 用户登录态管理
- Token 与 localStorage 同步
- 菜单权限列表管理
- 按钮级权限控制方法

### HTTP 请求
- 统一的 axios 实例
- 请求拦截：自动添加 `adminToken` header
- 响应拦截：统一错误处理、登录失效自动跳转
- baseURL 固定为 `/api`

## 开发规范

1. **使用 `<script setup>` 语法**，不使用 TypeScript
2. **接口请求统一放在 `src/api/` 目录**，禁止在页面直接使用 axios
3. **字段命名与后端保持一致**（驼峰命名）
4. **路径形式**：`/api/<模块名>/<动作>`
5. **三段式页面结构**：搜索区 → 表格 → 分页
6. **新增/编辑使用弹窗**，且抽成独立组件
7. **删除操作必须二次确认**
8. **按钮权限通过 `userStore.hasMenuCode()` 控制**
