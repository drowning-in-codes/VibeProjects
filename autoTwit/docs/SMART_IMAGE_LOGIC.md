# 智能配图判断逻辑说明

## 🤖 智能判断规则

autoTwit 会根据推文内容**自动判断**是否需要生成配图，无需手动指定。

---

## 📋 判断逻辑

### 1️⃣ 长度判断

```python
# 太短的推文不配图
if len(tweet_content) < 40:
    return False  # 不生成图片
```

**示例**：
- ✅ "早安" → 无图
- ✅ "谢谢大家的支持" → 无图

---

### 2️⃣ 适合配图的关键词

如果推文包含以下关键词，**自动生成配图**：

#### 科技类
```
AI, 人工智能, GPT, Claude, 技术, 科技, 代码, 编程
```

#### 产品类
```
产品, 发布, 上线, 推出, 新功能, 更新
```

#### 教程类
```
教程, 指南, 如何, 方法, 步骤, 技巧
```

#### 视觉化内容
```
设计, 界面, UI, UX, 图表, 数据, 趋势
```

#### 场景描述
```
未来, 世界, 城市, 空间, 场景
```

**示例**：
- ✅ "GPT-4 展现了惊人的能力" → **生成配图**
- ✅ "如何使用 Claude 提高效率" → **生成配图**
- ✅ "产品正式发布" → **生成配图**

---

### 3️⃣ 不适合配图的关键词

如果推文包含以下关键词，**不生成配图**：

#### 简单问候
```
早安, 晚安, 早上好, 晚上好, 周末愉快
```

#### 纯观点
```
我认为, 个人观点, 想法分享
```

#### 简单互动
```
感谢, 谢谢, 欢迎, 恭喜
```

**示例**：
- ✅ "早安，新的一天开始了" → **无图**
- ✅ "感谢大家的支持" → **无图**
- ✅ "我认为这个方向不错" → **无图**

---

### 4️⃣ 描述性词汇判断

如果包含以下词汇，**倾向生成配图**：

```
展示, 呈现, 看到, 观察, 发现, 效果
```

**示例**：
- ✅ "展示了最新的设计效果" → **生成配图**
- ✅ "观察到一个有趣的现象" → **生成配图**

---

### 5️⃣ 默认规则

```python
# 如果以上规则都不匹配
if len(tweet_content) > 80:
    return True   # 长推文配图
else:
    return False  # 短推文无图
```

---

## ⚙️ 使用方式

### 方式 1：自动判断（推荐）

```bash
python main.py generate "AI 技术的未来"
```

系统会：
1. 生成推文
2. **自动判断**是否需要配图
3. 如果需要，调用 DALL-E 生成

**日志输出**：
```
[INFO] 推文生成成功: AI 技术展现了...
[INFO] 智能判断：该推文适合配图
[INFO] 使用 DALL-E 3 生成图片...
```

---

### 方式 2：强制配图

```bash
python main.py generate "早安" yes
```

即使推文是"早安"，也会强制生成配图。

---

### 方式 3：强制无图

```bash
python main.py generate "AI 技术很厉害" no
```

即使推文适合配图，也不生成。

---

## 📊 判断流程图

```
推文内容
    │
    ├─ 长度 < 40 字？
    │   └─ 是 → ❌ 无图
    │
    ├─ 包含"适合配图"关键词？
    │   └─ 是 → ✅ 生成图
    │
    ├─ 包含"不适合配图"关键词？
    │   └─ 是 → ❌ 无图
    │
    ├─ 包含描述性词汇？
    │   └─ 是 → ✅ 生成图
    │
    └─ 默认规则
        ├─ 长度 > 80 字 → ✅ 生成图
        └─ 长度 ≤ 80 字 → ❌ 无图
```

## 🔧 自定义判断逻辑

如果你想修改判断规则，编辑 `src/ai/generator.py`：

```python
def should_generate_image(self, tweet_content: str) -> bool:
    """智能判断推文是否需要配图"""
    
    # 修改这里的规则
    if "你的关键词" in tweet_content:
        return True
    
    # 或调整长度阈值
    return len(tweet_content) > 100  # 改为 100 字
```
