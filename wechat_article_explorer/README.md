# 微信读书公众号文章浏览器

一个本地加载的 Chrome / Edge Manifest V3 扩展。它会在微信读书与微信公众号原文页添加“公众号文章”入口，用当前浏览器中的微信读书登录会话展示你在微信读书 App 内关注的公众号及其文章。

## 使用方法

1. 在浏览器打开 `chrome://extensions`（Edge 使用 `edge://extensions`），开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录 `wechat_article_explorer`。
3. 打开并登录 [微信读书](https://weread.qq.com)，并保持至少一个微信读书标签页打开。
4. 打开任意微信读书页面或微信公众号原文页，点击右下角“公众号文章”。
5. 在侧边栏中点击“在微信读书中搜索或管理公众号”，可在打开的微信读书官方页面手动搜索、关注或管理公众号；完成后返回侧边栏点击“刷新已关注列表”。

## 功能

* 列出微信读书 App 中已关注的公众号。
* 查看公众号文章标题、摘要、发布时间、阅读数和点赞数。
* 在新标签页打开公众号原文。
* 在微信读书页和公众号原文页使用同一侧边栏。
* 提供前往微信读书官方公众号/书架页面的手动管理入口。

## 登录与隐私

扩展在已打开的微信读书页面中使用浏览器已有的登录会话。它不会保存、上传或导出 cookie。登录失效时，请在微信读书网页重新扫码登录，并保持该标签页打开。

## 限制

数据来自微信读书的非公开接口，接口字段或可用性可能变化。仅会显示你在微信读书 App 内关注的公众号。
搜索、关注和取消关注不会在扩展内自动执行，均需由你在微信读书官方页面手动完成；该入口不会读取或保存公众号全文。
