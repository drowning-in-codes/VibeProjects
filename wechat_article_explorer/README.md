# 微信读书 · 公众号文章浏览器与导出器

一个轻量的 Chrome / Edge Manifest V3 浏览器扩展。它把微信读书中的公众号文章集中到浏览器侧边抽屉中，支持按公众号检索、筛选、浏览和导出文章。

> 项目仍在持续迭代中。如果你遇到接口变化、页面兼容问题或有改进想法，欢迎提交 Issue 或 Pull Request。

## 功能概览

### 公众号管理

- 从微信读书书架刷新已关注的公众号。
- 按公众号名称搜索并添加公众号。
  - 公众号名称搜索需要先在浏览器中打开并登录公众号后台。
  - 搜索使用公众号后台登录态，与微信读书登录态相互独立。
- 粘贴公众号文章完整链接、`__biz`、公众号 `fakid` 或 `MP_WXS_数字` 添加公众号。
  - 什么是 `__biz`：`__biz` 是微信公众号的唯一标识，藏在每篇公众号文章链接的 `__biz=` 参数里，例如 `https://mp.weixin.qq.com/s?__biz=MzIx...` 中 `__biz=` 后面那段。它用来唯一定位一个公众号。复制整条文章链接（或其中的 `__biz=...` 片段）粘贴到输入框，扩展会自动解析出对应公众号并加入查看范围。
  - 什么是 `MP_WXS_`：`MP_WXS_` 是微信读书里给公众号分配的 `bookId`，形如 `MP_WXS_123456789`（前缀固定，后跟一串数字）。在微信读书接口里每个公众号都用它来标识，扩展内部也用这个作为公众号的唯一键。粘贴 `MP_WXS_数字` 即可直接添加对应公众号。
- 在公众号文章页面直接识别当前公众号，并一键收录当前文章或当前公众号。
- 将微信读书关注的公众号添加到“文章查看范围”列表。
- 将查看范围里的公众号批量添加到微信读书关注。
- 本地公众号列表会缓存在浏览器本地存储中，重新打开页面后仍可使用。

### 三个“公众号列表”的区别

这个扩展里涉及三个容易混淆的“列表”，它们互不相同：

| 概念 | 数据来源 | 作用 |
| --- | --- | --- |
| 微信关注公众号 | 你在微信里关注的所有公众号 | 与扩展无关，仅作为“你已关注的号”的参照 |
| 微信读书关注 / 书架 | 微信读书里你关注、加入书架的公众号 | 扩展读取这个列表，作为“候选公众号” |
| 文章查看范围 | 你在扩展里主动添加的公众号 | 真正执行文章拉取的范围 |

- **微信关注公众号** 是微信（App / 公众号后台）里的关注关系，扩展不会、也无法直接读取它。
- **微信读书关注 / 书架** 是微信读书里的关注关系，点击“刷新关注列表”可以读到；这里的公众号不会自动参与拉取。
- **文章查看范围** 是扩展本地维护的列表，只有进入这里的公众号才会被“拉取文章”。你可以通过搜索、粘贴文章链接 / `__biz`、或点击公众号文章页的“加到查看范围”来添加。

简单说：**微信关注** ≠ **微信读书书架** ≠ **文章查看范围**。只有“文章查看范围”里的号才会被拉取文章；把“微信读书关注”里的号点“添加到查看列表”后，它才进入查看范围。

### 文章浏览

- 按公众号分组展示文章，并显示公众号名称和文章数量。
- 每个公众号默认显示 3 篇文章。
- 点击“显示更多”后，每次增加显示 5 篇。
- 支持按标题、公众号名称进行关键词筛选。
- 支持按发布日期筛选。
- 支持直接打开公众号原文链接。

### 导出与界面

- 导出 CSV。
- 导出 Markdown。
- 一键复制文章链接。
- 一键复制文章标题和链接。
- 支持深色/浅色模式切换，并记住上次选择。
- 支持扫码登录微信读书，并在未登录时给出提示。
- 提供诊断导出功能，便于排查微信读书接口字段变化。

## 公众号 Tab 的区域

公众号 Tab 顶部是“文章查看与获取”区域，集中展示当前拉取范围、每个公众号的文章数量限制和“拉取文章”操作。下面按用途分为三部分：

1. **搜索/添加公众号**：通过公众号名称、文章链接、`__biz` 或 `MP_WXS_数字` 添加公众号。
2. **文章查看范围**：实际执行文章拉取的范围。搜索或添加成功后会进入这里，可以移除不需要的公众号。
3. **微信读书关注的公众号**：微信读书书架中的关注列表。点击某个公众号的“添加到查看列表”后，才会参与文章拉取。

这种分离可以避免“微信读书关注列表”和“本次想查看的公众号列表”混在一起，也不需要通过勾选框管理拉取范围。

## 安装

1. 下载或克隆本项目。
2. 打开浏览器扩展管理页面：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角的**开发者模式**。
4. 点击**加载已解压的扩展程序**。
5. 选择本项目中的 `wechat_article_explorer` 目录。
6. 打开 [微信读书](https://weread.qq.com) 或微信公众号文章页面，例如：
   `https://mp.weixin.qq.com/s/...`
7. 点击页面右侧的“公众号导出”按钮打开扩展抽屉。

## 快速使用

### 1. 登录微信读书

文章读取依赖微信读书登录态。未登录时，扩展会在面板顶部显示登录提示，可以点击登录按钮唤起微信读书官方登录入口并扫码。

### 2. 添加公众号

可以选择以下任一方式：

- 点击“打开公众号后台”，登录后使用公众号名称搜索；
- 粘贴公众号文章的完整链接；
- 粘贴文章链接中的 `__biz`；
- 粘贴公众号 `fakid` 数字；
- 粘贴 `MP_WXS_数字`；
- 在公众号文章页面点击“收录这个号”。

### 3. 选择查看范围

先在顶部“文章查看与获取”区域确认当前范围；如果需要新增公众号，可在下方“微信读书关注的公众号”区域点击“刷新关注列表”，再点击目标公众号旁边的“添加到查看列表”。搜索结果和链接添加的公众号会直接进入查看列表。

查看列表中的公众号就是文章拉取范围。确认列表后，设置每个公众号最多拉取的文章数量：

- 默认最多 10 篇；
- 输入 `0` 表示不限制。

点击“拉取文章”开始读取。

### 4. 查看与导出

拉取完成后切换到“文章” Tab：

- 使用关键词和日期条件筛选；
- 按公众号展开文章；
- 点击文章标题或“原文 ↗”打开原文；
- 使用 CSV、Markdown 或复制按钮导出结果。

## 数据来源与接口

扩展只使用浏览器当前登录态访问以下站点：

- `https://weread.qq.com`
  - `GET /web/shelf/bookIds`：读取微信读书书架。
  - `GET /web/book/info?bookId=`：读取公众号名称。
  - `GET /web/mp/articles?bookId=&offset=`：读取公众号文章列表。
  - `GET /api/mp/cover?bookId=`：文章列表失败时的单篇兜底接口。
  - `POST /mp/shelf/addToShelf`：用户主动点击加入书架时使用。
- `https://mp.weixin.qq.com`
  - `GET /cgi-bin/searchbiz`：按名称搜索公众号，需要公众号后台登录态。

在微信公众号页面中，微信读书请求会由扩展的 `background.js` 代理，以避免跨域限制。扩展后台只放行项目需要的站点和路径，不提供任意网址代理。

## 隐私与权限说明

- 扩展需要 `storage` 权限，用于保存公众号列表、文章缓存、界面主题和最近使用的 Tab。
- 扩展只注入 `weread.qq.com` 和 `mp.weixin.qq.com`。
- 公众号后台搜索使用浏览器已有的登录态，不保存或上传公众号后台密码。
- 文章、公众号和登录信息不会主动发送到项目作者或第三方服务器。
- 文章缓存保存在浏览器本地；清除扩展存储后，本地列表和缓存会被删除。

## 常见问题

### 刷新关注列表提示未登录

请确认当前浏览器已经登录微信读书。如果登录态失效，点击登录提示重新扫码；也可以直接打开微信读书首页确认登录状态。

### 公众号名称搜索没有结果或提示登录

公众号名称搜索使用的是公众号后台登录态，不是微信读书登录态。请点击“打开公众号后台”，完成登录后返回扩展，再重新搜索。

### 搜索提示登录态过期或被限流

- `200003`：公众号后台登录态已过期，请重新登录。
- `200013`：公众号后台搜索被限流，请稍后重试，或改用公众号文章链接添加。

### 文章读取失败或出现 `-2041`

`-2041` 通常表示请求频率限制或环境风控。请稍后重试，减少一次拉取的公众号数量，或降低拉取频率。扩展已经在分页和详情请求之间加入延迟，但无法绕过微信读书服务端的风控策略。

### 公众号已经关注但没有文章

微信读书书架中的公众号与“文章查看范围”是两个列表。请先点击该公众号的“添加到查看列表”，再点击“拉取文章”。

### 页面没有显示扩展按钮

请确认：

1. 扩展已在扩展管理页面启用；
2. 当前地址是 `weread.qq.com` 或 `mp.weixin.qq.com`；
3. 已重新加载扩展并刷新当前页面；
4. 没有被浏览器的页面脚本限制或其他扩展拦截。

## 本地开发与验证

本项目是无构建步骤的浏览器扩展，主要文件如下：

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | Manifest V3 配置、权限和注入入口 |
| `content.js` | 页面注入、状态管理、界面和主要业务逻辑 |
| `content.css` | 抽屉、公众号列表和文章列表样式 |
| `background.js` | 跨域请求代理、标签页打开和公众号后台搜索代理 |

修改后可以运行以下检查：

```powershell
node --check content.js
node --check background.js
Get-Content manifest.json | ConvertFrom-Json | Out-Null
git diff --check
```

完成代码修改后，在 `chrome://extensions` 或 `edge://extensions` 中点击扩展的刷新按钮，再刷新测试页面。
