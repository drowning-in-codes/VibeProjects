# 微信读书公众号文章浏览器

一个本地加载的 Chrome / Edge Manifest V3 扩展。它会在微信读书与微信公众号原文页添加“公众号文章”入口，用当前浏览器中的微信读书登录会话展示你在微信读书 App 内关注的公众号及其文章。

## 使用方法

1. 在浏览器打开 `chrome://extensions`（Edge 使用 `edge://extensions`），开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录 `wechat_article_explorer`。
3. 打开并登录 [微信读书](https://weread.qq.com)，并保持至少一个微信读书标签页打开。
4. 打开任意微信读书页面或微信公众号原文页，点击右下角“公众号文章”。
5. 在微信公众号页面的侧边栏使用“公众号后台搜索”，提交名称/关键词后选择公众号，再按“加载更多”读取文章元数据。此入口不是微信关注列表，也不会自动关注公众号。
6. 在搜索结果或已搜索公众号列表旁点击“关注”，即可把公众号加入扩展本地关注列表；点击“已关注”可取消。已关注公众号会在公众号后台首页显示，点击名称即可直接读取文章。
7. 在微信读书页面中点击“在微信读书中搜索或管理公众号”，可在官方页面手动搜索、关注或管理公众号；完成后返回侧边栏点击“刷新已关注列表”。

## 功能

* 列出微信读书 App 中已关注的公众号。
* 查看公众号最新文章的封面（如可用）、来源名称、标题、摘要、发布时间、阅读数和点赞数。
* 在新标签页打开公众号原文。
* 通过按钮打开该公众号的微信读书阅读页，查看完整文章历史。
* 在微信读书页和公众号原文页使用同一侧边栏。
* 在 `mp.weixin.qq.com` 页面由用户主动搜索公众号后台并串行分页读取多篇文章元数据。
* 在扩展本地保存最多 50 个公众号的标识和展示元数据，提供已关注列表和一键取消。
* 提供前往微信读书官方公众号/书架页面的手动管理入口。

## 登录与隐私

扩展在已打开的微信读书页面中使用浏览器已有的登录会话。它不会保存、上传或导出 cookie。登录失效时，请在微信读书网页重新扫码登录，并保持该标签页打开。
读取最新文章时，扩展会使用书架记录中的微信读书公众号阅读页面作为同源请求上下文，请求 `GET /api/mp/cover?bookId=MP_WXS_<id>`；必要时创建一个临时标签页，请求完成后关闭。
公众号后台搜索和文章列表请求在当前 `mp.weixin.qq.com` 页面的 MAIN 上下文执行；页面 token 只在该上下文临时读取，不会传给内容脚本或保存。扩展只在本地缓存搜索结果中公众号的标识和展示元数据。
扩展中的“关注”是本地阅读清单，不会调用微信关注接口，也不代表微信官方关注关系。

## 限制

数据来自微信读书及公众号后台的非公开接口，接口字段或可用性可能变化。公众号后台结果是公开出版信息发现，不代表用户关注关系。只保存文章元数据和官方原文链接，不获取正文、评论或媒体；遇到登录失效、限流、验证码或未知结构会停止请求。
搜索、关注和取消关注不会在扩展内自动执行，均需由你在微信读书官方页面手动完成；该入口不会读取或保存公众号全文。
